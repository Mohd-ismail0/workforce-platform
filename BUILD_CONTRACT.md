# Initial build integration contract

Scope: working local multi-integration platform, not production certification. Follow docs/build-spec. Backend Go, PostgreSQL/pgx, River OSS transport. Frontend React TS Vite. Independent code, no Agency code/assets. Real provider writes disabled. Test adapters prominently labeled simulator. Module go name `workforce.local/platform`.

API prefix /api/v1. JSON snake_case. Errors {error:{code,message}}. Auth initial explicit local test only: Authorization Bearer configured opaque session keys mapping to org/user/role server side; never trust org header. No auth default. Production OIDC must refuse startup if unavailable, do not pretend test tokens are OIDC.

Local identities: requester, approver and second-org requester, credentials configured outside tracked files. Role values requester/approver/admin; admin does not waive separate-human approval. All lists return {items:[]}. Object response direct object. IDs opaque strings generated by backend.

Task: {id,org_id,title,description,status,owner_id,assignee_id,project_id,version,created_at}; status draft/ready/in_progress/in_review/blocked/done/cancelled. Project {id,name,description}. Agent definition {id,name,harness,status,owner_id,capabilities:[]}; harness registration can be unavailable (not fake runnable).

Proposal: {id,task_id,revision,digest,status,summary,operations:[],created_at}; status pending_endorsement/pending_approval/approved/rejected/superseded/executing/done/needs_attention. Operation {id,integration,action,target_id,expected_version,payload:{}}. Initial simulator integration IDs inventory/mail/documents; action adjust/send/update respectively. Simulator execution still gated. No arbitrary URL/shell execution.

GET /health, GET /ready. GET /api/v1/me -> {id,org_id,role,name}. GET/POST /api/v1/projects. GET/POST /api/v1/tasks; create {title,description,assignee_id?,project_id?}; GET /tasks/{id}; POST /tasks/{id}/dependencies {parent_id}; POST /tasks/{id}/cancel {expected_version}. GET/POST /api/v1/agents. GET /api/v1/integrations. GET /api/v1/integrations/{id}/records (authorized simulated read). POST /tasks/{id}/proposals {summary,operations:[]}; GET /proposals (all permitted); GET /proposals/{id}; POST /proposals/{id}/endorse {revision,digest}; POST /proposals/{id}/approve {revision,digest}; POST /proposals/{id}/reject {revision,digest,reason}; GET /decisions -> {items:[{id,task_id,proposal_id,revision,digest,kind,title,status}]}; GET /events -> {items:[]}; GET /receipts -> {items:[]}. POST /tasks/{id}/handoffs {recipient_id,role,summary}; POST /handoffs/{id}/accept. UI may show explicitly unavailable unsupported operations; never invent API success.

Owned workstreams: backend owns go.mod/go.sum cmd/ internal/platform internal/api internal/store migrations/; connector specialist owns internal/connectors/ only (standard library Go; interface in its own package described below); frontend owns web/ only; parent owns docs/root build/integration infrastructure. No concurrent git commits from children. TDD and record actual tests. Parent integrates and commits.

Connector package `internal/connectors`: define Operation (matching above), Record {ID string json:id, Version int json:version, Data map[string]any json:data}, Manifest {ID,Name,Kind string, Actions []string, Simulation bool} JSON snake_case, interface Connector {Manifest() Manifest; Validate(Operation) error; Prepare(current Record, op Operation) (Record,error)}. Prepare is PURE transformation, no mutation/network. Host owns persistent records, effect intents, transactions and readback. Registry NewRegistry(), List() []Manifest, Get(id string)(Connector,bool). Inventory validates positive or zero resulting integer quantities and explicit delta; documents typed title/content updates; mail requires recipients/subject/body and explicit attachments empty array or known refs, never actual email sends. Pure tests unsupported action/schema/negative stock/version mismatch; host handles idempotency/CAS. All operations bind resource record/version. Connector errors typed or conventional exported sentinels.

Integration mismatch: document in handoff, contact via summary; do not modify another stream's files. First local milestone is genuine end-to-end permission-scoped UI and persisted queue/approval/effects across multiple simulator connectors, with tested failure cases. Remaining full-product features tracked honestly, not claimed implemented merely because navigation exists.
